| 原代码/基线关系 | `UPSTREAM.md` 区分适配模块、核心重构和完整独立 baseline；classic 仅为评分函数对照 |

## 本次实现范围

新增/完善交付文档、固定配置、Docker/Compose、HTTP smoke、ZIP 打包及解压验证，并让 README 成为 service 的独立入口。Docker Health 使用实际 PORT，超时覆盖模型列表探测；镜像内固定读取离线配置。业务源码 `src/`、既有契约 `contracts/`、eval 和 workspace 编排没有因参考稿里的历史待办而改写。

历史设计仍有其价值，但“存在实现”“某配置启用”“特定历史实验有收益”“当前包已通过验收”是不同层次。本次交付分别记录，不把来源文档的断言自动升级为当前实现保证。
